Git Basics Hands-On Lab: Pulling, Clonging, Branches, .gitignore, and README

In this lab you will practice:
- Pulling changes from a remote repository
- Creating, switching, and merging branches
- Ignoring files with .gitignore
- Adding a README.md for documentation
- Cloning a repository to a new directory

Use HTTPS for all remote operations (authenticate with your username and a Personal Access Token).

Pre-requisites:
-------------------
  git config --global user.name "Your Name"
  git config --global user.email "you@example.com"
  git config --global init.defaultBranch main
  git config --global credential.helper 'cache --timeout=3600'
  git clone https://github.com/<your-username>/hello-git.git (or whatever you named it)
  cd hello-git (or whatever you named it)


Step 1   — Pull Changes from the Remote Repository
-------------------

1. On GitHub, open your repo and edit hello-git.txt directly in the browser.
   Add a new line (e.g., "Change made on GitHub").
2. Back in your terminal:
   git pull              <-- provide your username and PAT when prompted
   cat hello-git.txt


Step 2 — Introduction to Branches: Create, Switch, and Merge
-------------------

# Look at current branches
git branch

# Create a new branch and switch to it
git branch feature-welcome
git branch        # confirm the new branch exists
git checkout feature-welcome

# Make a change on the branch
echo "Feature branch update" >> hello-git.txt
git status
git add hello-git.txt
git commit -m "Update hello-git.txt on feature-welcome"

# Switch back to main and merge
git checkout main
git merge feature-welcome
git branch
git branch -d feature-welcome

# Push the updated main to the remote
git push


Step 3 — Ignore Specific Files with .gitignore
-------------------

echo "debug.log" > debug.log
git status
echo "*.log" > .gitignore
git status
git add .gitignore
git commit -m "Add .gitignore to ignore log files"
git status      # confirm debug.log is untracked (ignored)
git push


Step 4 — Create a README for Project Documentation
-------------------

echo "# hello-git" > README.md
echo "This repository is used to practice Git basics: pull, branches, .gitignore, and README." >> README.md
echo "## This is a subheading" > README.md

git add README.md
git commit -m "Add README with project documentation"
git push


STEP 5 - View Your Changes on GitHub
-------------------

1. Go to your repository page on GitHub.
2. Verify that hello-git.txt, .gitignore, and README.md reflect your changes


STEP 6 - Clone a Repository to a new Directory
-------------------

1. Navigate out of your current directory:
    cd ..

2. Clone your repository into this new directory:
    git clone https://github.com/btkrausen/git-made-easy

By the End of This Lab You Practiced:
- Pulling changes from a remote repository
- Creating, switching, and merging branches
- Ignoring files with .gitignore
- Documenting your project with README.md
